# Competitor gaps

Internal planning note. This list is not part of the public roadmap.

These are features other living-dex trackers, official storage, and reference sites already offer, and that Retro Pokédex does not yet. None of them are scheduled.

## Collection

- **A PC box grid.** Pokédex Tracker and Pokémon HOME show a living dex as 30-slot boxes, which is also the shape the screenshot scanner fills. Today the collection is a list and a set of species marks.
- **A page you can share.** Pokédex Tracker offers a public link to caught and shiny progress that someone else can open without an account.
- **Export.** Pokédex Tracker can download marks and specimens as a file you can keep or move.
- **Progress by evolution family.** Pokédex Tracker shows which stage of a line is still missing, instead of only the single species.

## Living-dex goals

- **Pattern and form sets.** Living-dex trackers treat Unown’s letters, Vivillon’s patterns, Alcremie’s sweets, and similar sets as their own lists. Mega, regional, and Gigantamax forms already have lists; these sets do not.
- **Ball, language, and ribbon goals.** Living-dex challenges and Pokémon HOME track a species caught in a given Poké Ball, from a given language, or with a given ribbon. Specimens can store a ball today; they are not a completion goal.
- **Alpha, Jumbo, and Tiny.** Legends: Arceus and Scarlet / Violet trackers mark Alpha Pokémon and the Jumbo and Tiny sizes in the same place shinies are marked.
- **A shiny hunt counter.** Shiny-hunt trackers count encounters or eggs toward one shiny, kept on that species for the game you are playing.

## Reference

- **Event distributions.** Serebii keeps a checklist of mythicals and event distributions, with where and when they were available.
- **Breeding and egg moves.** Pokémon Database covers egg groups, what can pass an egg move, and the chain required to breed it. An imported specimen can show an egg location; there is no breeding guide.
- **Search from a move or a place.** Pokémon Database and Serebii let you start from a move and see who learns it, or start from a route and see who is there. Today you start from the Pokémon.
- **A damage calculator.** Pokémon Showdown and Pokémon Database calculate damage with items, abilities, and a Tera type filled in. The species page has defensive matchups and recommended sets, not a calculator.
- **Items on the map.** Serebii lists TMs, hidden items, and other pickups on location pages, next to the wild Pokémon that region maps already draw.
